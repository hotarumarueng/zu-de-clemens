# ADR 0003: 図は自動で描かず、提案して押されたときだけ描く

## ステータス

採用 — 2026-10-17

## コンテキスト

当初の設計では、Jev の確率がしきい値以上なら、すぐに fork で図を描いてペインに出していた。Jev の判定が外れると、不要な図のために Claude の使用量を消費し、利用者には邪魔な図が出る。

Claude のデスクトップアプリは、画面右側にペインを自動で開ける。

## 決定

しきい値以上でも、図は描かない。ペインに「この返答は図で解説できます」という提案と、［図にする］［今回はいらない］のボタンを出す。［図にする］が押されたときだけ fork で描く。

自動で描きたい人向けに、設定でオートモードを用意する。非推奨とし、既定は OFF にする。

## 結果

- 判定が外れても、出るのは提案の 1 行だけで、Claude の使用量は消費しない
- 提案への反応（押した／いらない／放置）がそのまま評価になり、評価ボタンが要らなくなった。回答ログにラベル付きのデータがたまり、しきい値の見直しに使える
- 空振りの損が小さくなったので、しきい値は見逃しを減らす側に寄せる（設計 13 章）
- 押してから図が出るまで、数秒〜十数秒待つ
- 質問ダイアログを開いているあいだにペインのボタンを押せるかは未確認。押せなければ、R1（質問のとき）だけ自動で描く
