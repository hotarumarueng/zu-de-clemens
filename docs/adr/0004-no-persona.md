# ADR 0004: 読み手のペルソナを扱わない

## ステータス

採用 — 2026-10-16（2026-10-04 の「Jev にペルソナを JSON で渡す」を取り消し）

## コンテキスト

当初は、explainer プラグインのペルソナ（読み手が知っていること・知らないこと・読み方）を Jev の判定材料に含め、読み手に合わせて「図にすべきか」を判定する予定だった。図が要るかは読み手によって変わるため、精度が上がると見ていた。

## 決定

ペルソナを扱わない。Jev の判定材料は、判定対象の文と、利用者の直近の入力 3 件だけにする。

理由：ペルソナ（読み手に合わせた説明）は、作者が別に作っているプロダクトの領域と重なるため、zu-de-clemens では扱わない。

## 結果

- 判定は、平均的な読み手を想定したものになる
- 評価は、ペルソナあり・なしの比較ではなく、評価データ 30 件と回答ログで行う
- explainer への依存がなくなった。D2 の書き方と検査の手順は、zu-de-clemens の中で定義する
