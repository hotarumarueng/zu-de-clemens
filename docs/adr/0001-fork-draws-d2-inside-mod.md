# ADR 0001: 図は MOD の中で、会話の複製（fork）に D2 を書かせて作る

## ステータス

採用 — 2026-10-04（試験で実現性を確認 — 2026-10-16）

## コンテキスト

会話の内容に合う図を、Claude Code のサイドペインに出したい。特に、Claude が質問ダイアログ（AskUserQuestion）を出したときに、選択肢を比べる図をダイアログの横に出したい。

質問ダイアログを出しているあいだ、本体の Claude は回答を待って止まる。本体に「図を描いて」と頼んでも、回答するまで動けない。

## 検討した案

| 案 | 図を書くもの | 図が出る場所 | 質問ダイアログの横に図 |
|---|---|---|---|
| A | MOD の中で、会話の複製（`$.model.fork`） | サイドペイン | 出せる |
| B | 本体の Claude（スキル経由） | サイドペイン | 出せない |
| C | MOD を使わない（通常のフックと会話内の図） | 会話の中 | 出せない |

## 決定

A を採る。fork は会話の複製なので、経緯を知った Claude が図の種類とおすすめを決められる。図の言語は D2 にする。テキストなので Claude が書きやすく、`d2 validate` で検査でき、SVG と文字の図を出せる。

## 結果

- 2026-10-16 の使い捨て試験（Claude Code 2.1.301、デスクトップアプリ）で、MOD から D2 の実行（`$.process.run`）、ペインへの `Svg` 表示、Jev への通信、データ置き場への書き込みができることを確認した
- MOD は early access の function hooks に依存する。Claude Code の更新で壊れる可能性がある
- 利用者は D2 を入れる必要がある（README に手順を書く）
- fork は Claude の使用量を消費する。描くのは利用者が求めたときだけにする（ADR 0003）
