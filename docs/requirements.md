## 目的

会話の内容に合う図を Claude Code が選んで描き、サイドペインに出す MOD。
文章だけでは構造（部品の関係・影響範囲）が頭に入りにくい読み手が、会話を遡らずに理解・判断できるようにする。

## 利用者

- 作者本人に加え、他の Claude Code 利用者にも配る（2026-10-16 決定）
- 配布は公開 GitHub リポジトリをマーケットプレイスとし、プラグインとして入れてもらう

## 要件（EARS 形式）

- R1: Claude が AskUserQuestion で質問したとき、MOD は「図にすべきか」を判定し、確率がしきい値以上なら、図の提案（図の種類の候補と確率）と［図にする］［今回はいらない］のボタンをペインに出す。［図にする］が押されたときだけ、選択肢を比べる図とおすすめを作って表示する
- R2: Claude の応答が終わったとき、MOD は「図にすべきか」を判定し、確率がしきい値以上なら、R1 と同じ形で図の提案を出す。［図にする］が押されたときだけ、その説明の図を作って表示する
- R3: 利用者がプロンプトを送ったとき、MOD は「セッションの整理を頼んでいるか」を判定し、確率がしきい値以上なら、R1 と同じ形で図の提案を出す。［図にする］が押されたときだけ、話題ごとの進み具合の図を作って表示する
- R4: （欠番。ペルソナを外したため 2026-10-16 に削除）
- R5: MOD は D2 を検査（`d2 validate`）してから SVG に変換する。検査に失敗したら、エラー文を添えて 1 回だけ書き直させる。2 回目も失敗したら、図を出さずに失敗したことをペインに表示する
- R6: ペインは図・おすすめ・判定の確率を表示する（評価ボタンは置かず、図の提案への反応を評価として扱う）
- R7: 利用者が質問に答えたとき、または図の提案に反応したとき（押した／いらない／放置）、MOD は回答ログに追記する。回答ログはプラグイン用のデータ置き場に、プロジェクトごとの Markdown ファイルとして保存する
- R8: 図の検品が ON のとき、MOD は描いた図を PNG にして Jev に渡し、文字の重なり・流れの向き・狙った図の種類に見えるかを判定する。不合格なら書き直させる（実験機能。既定は OFF）
- R9: Jev の API キーまたは D2 が見つからないとき、MOD は図を出さずに、足りないものと README の導入手順への案内をペインに表示する
- R10: README は、Claude が読んで導入を代行できる手順（D2 の導入、マーケットプレイスの追加、プラグインのインストール）を含む。API キーはプラグインの設定項目（`userConfig`、`sensitive: true`）に利用者本人が入力する手順とし、Claude に貼り付けさせない
- R11: 公開前に、会話の例 20〜30 件に「図がほしい／要らない」を付けた評価データを `evals/` に置き、Jev の確率と照らして外れが最も少ないしきい値を既定値にする。評価データは実際の会話を写さず、場面をもとに書き起こす
- R12: 利用者はしきい値をプラグインの設定（userConfig）で変更できる
- R13: MOD は図の種類カタログ（約 15 種。種類ごとに、どんな会話で使うかと D2 の型の見本を持つ）を、Jev の Choice の選択肢と、fork に渡す描き方の指示の両方に使う
- R14: ペインの表示・おすすめ・README は日本語と英語に対応する
- R15: 設定でオートモードを ON にすると、提案を出さずに、しきい値以上で図を自動で作って表示する（非推奨。既定は OFF。判定が外れるたびに Claude の使用量を消費するため）

## 「セッションの整理を頼んでいるか」の定義

このセッションで、話題の全体像と進み具合（何が決まり、何が残っているか）を整理してほしいと頼んでいるか。特定のもの（エラー・ビルドなど）の状態を聞く場合は「いいえ」。

| はい | いいえ |
|---|---|
| 今このセッションどうなってる？ | D2って何？ |
| 話があちこち行ったけど、何が決まった？ | A案で進めて |
| どこまで終わったっけ | この関数のエラーどうなってる？ |
| いったん整理して | ジェブって無料じゃね？ |

## 検証済み（2026-10-16、使い捨て試験・Claude Code 2.1.301・デスクトップアプリ）

- デスクトップアプリの MOD から `$.process.run` で D2 を実行できる（型定義の「CLI only」はデスクトップアプリでも当てはまる）
- D2 は標準入出力で日本語の図を SVG にできる（4,705 文字、約 12 ミリ秒）
- ペインに `Svg` 要素で図を表示できる。ただし、ダークモードの画面に白地の図がそのまま出る。小さな図もペインいっぱいに拡大される
- MOD から `$.http.fetch` で Jev を呼べる（HTTP 200、入力 304 トークン）
- MOD から `$.fs` でプラグイン用のデータ置き場（`~/.claude/plugins/data/` 配下）に書ける
- 応答の終わりは `turn.complete` イベントで拾え、本文は `answer` に入る（型定義で確認）
- デスクトップアプリの MOD からは、zsh で設定した環境変数（`TYPESAFE_API_KEY`）が見えない

## 未検証

- `userConfig` の `sensitive: true` の値が MOD の `options` に渡るか（型定義上は渡る読みだが、明記はない）
